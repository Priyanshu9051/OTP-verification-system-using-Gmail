# OTP-verification-system-using-Gmail
A Python-based OTP verification system that sends a one-time password (OTP) to a Gmail account using SMTP for secure email-based authentication.

# 🔐 OTP Verification Using Gmail (Python)

This project is a **Python-based OTP (One-Time Password) Verification System** that sends an OTP to a user's Gmail account using **SMTP**.  
The user verifies the OTP by entering it in the terminal.

This project helps in understanding **email automation, authentication, and security concepts** in Python.

---

## 🚀 Features
- 🔢 Generates a random 6-digit OTP
- 📧 Sends OTP to Gmail using SMTP
- ✅ Verifies user-entered OTP
- 🔐 Uses Gmail App Password for secure login
- 🧠 Simple and beginner-friendly

---

## 🛠️ Technologies Used
- **Python 3**
- **smtplib** (built-in)
- **ssl** (built-in)
- **random**
